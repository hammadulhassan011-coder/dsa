## 🛠️ How to Add Your Solutions

1. Check the lecture number in [**`course-syllabus.md`**](./course-syllabus.md).
2. Go to the corresponding module in `topics/` (e.g. `topics/01-basics-and-math/`).
3. Copy the starter template:
   ```bash
   cp templates/solution_template.py topics/01-basics-and-math/005_digit_extraction.py
   ```
4. Write your solution and test assertions.
5. Log the problem in `progress-tracker.md`.
6. Commit & push:
   ```bash
   git add .
   git commit -m "Complete Lecture 005: Digit Extraction"
   git push
   ```
