# Data Structures & Algorithms (DSA) Practice 🚀

Welcome to my daily DSA learning repository! This repository is dedicated to building strong problem-solving skills, mastering core data structures and algorithms, and maintaining a consistent daily coding habit.

---

## 📌 Repository Structure

The repository is structured topic-by-topic so every data structure and algorithm has its dedicated space:

```text
dsa/
├── README.md                      # Overview & navigation
├── progress-tracker.md            # Daily learning & problem log
├── templates/
│   └── solution_template.py       # Starter template for new problems
├── topics/
│   ├── 01-basics-and-math/        # Time complexity, basic math, bit manipulation
│   ├── 02-arrays-and-strings/     # 2 pointers, sliding window, prefix sums
│   ├── 03-linked-lists/           # Singly, doubly, circular linked lists
│   ├── 04-stacks-and-queues/      # Monotonic stack, queues, deque
│   ├── 05-searching-and-sorting/  # Binary search, merge sort, quick sort
│   ├── 06-recursion-and-backtracking/ # Subsets, permutations, N-Queens
│   ├── 07-trees-and-bst/          # Binary trees, traversals, BST operations
│   ├── 08-heaps-and-priority-queues/  # Min/Max heap, top-k elements
│   ├── 09-graphs/                 # BFS, DFS, Dijkstra, topological sort
│   └── 10-dynamic-programming/    # 1D/2D DP, knapsack, memoization/tabulation
└── setup.sh                       # Quick launcher for daily study session
```

## 🛠️ How to Add a New Problem

1. Navigate to the appropriate topic folder (e.g. `topics/02-arrays-and-strings/`).
2. Copy the template from [`templates/solution_template.py`](./templates/solution_template.py).
3. Name your file descriptively, e.g. `two_sum.py`.
4. Include intuition, time complexity, and space complexity in the header.
5. Add an entry to [**`progress-tracker.md`**](./progress-tracker.md).
6. Commit & push:
   ```bash
   git add .
   git commit -m "Add solution for Two Sum"
   git push
   ```
